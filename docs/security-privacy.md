# Security and privacy

Implemented: password hashing, random hashed sessions/recovery/sharing tokens, server authorization, scoped grants, exact-Origin mutation protection, persisted rate limits, schema validation, private GridFS downloads, audit metadata and environment-only credentials.

No owner phone is verified. No claim of clinical certification, HIPAA certification, regulatory verification or production readiness is made. The manual doctor label is admin-reviewed. Admins view account and operational metadata rather than medical records.

Source evidence and questions may leave the deployment for Groq. Upload UI discloses this processing; use synthetic reports. Provider retention, terms, jurisdiction and operator obligations require review before real data. Review summaries against originals.

Known operational gaps: account deletion/export policy, backups/restore, audit retention, administrative MFA/recovery, session-management UI, full localization, malware scanning, robust adversarial document resource isolation, crash-safe upload reconciliation, and independent penetration/clinical testing. Do not expose this demo publicly with real data.

Credentials supplied in the conversation are not saved in the project and should be rotated. .env.local, build products and dependencies are excluded from the ZIP.
