# Research gap and evaluation hypothesis

The design hypothesis is that patient-controlled historical records, source-linked retrieval and temporary scoped doctor access can improve continuity across unrelated outpatient providers. This is a product hypothesis, not a systematic literature review or a proven novelty claim.

Compare against manual folder search using the same synthetic set: time to find a previous test; correct report/date/value retrieval; citation traceability; incorrect or unsupported claims; revocation and scope denial rates. Record sample size and failures. No clinical outcome improvement is claimed.
